Buying Stars!

Sure, the demo version is great--more developed than most (if not all) demo (or shareware) games you'll find--but it's not enough. You can buy the full-blown, retail version off the store shelves, or via the Web, phone, fax or mail.

What's in the Retail Version?

In addition to the large number of features already in the demo version, you'll find you have access to technology all the way up to level 26. You'll also be able to create larger universes, have access to more advanced universe creation options, and save custom races.
