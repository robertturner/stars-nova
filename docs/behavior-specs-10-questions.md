# Questions for the spec team (behavior-specs-10)

Collected from the spec-10 audit and the three implementation passes that followed it. **Updated 2026-10-02 for spec-11:** nothing was deleted; each question that spec-11 answers carries an "**Answered by spec-11:**" suffix with the answer and whether the code agrees or must change (103 of the 106 questions), and every new gap the spec-11 analyses raised is collected in section 11 (146 questions). Each question names the spec location, says what we need, and says what the code does in the meantime
so you can tell how urgent it is. **Priority:** **A** = changes how the game plays or blocks a feature; **B** = a number or rule we have filled in and would like confirmed; **C** = wording, labels or cosmetic.

Where a question says "stand-in", the code uses a placeholder value we chose, not one from the specs. Nothing here was filled in from the original game, community wikis or help text except
the four items listed under "Values we should not be using" - please tell us whether to keep or remove those.
